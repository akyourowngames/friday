# AGENTS.md

## Friday Engineering Rules

- Do not hardcode natural-language assistant replies for greetings, memory recall, identity questions, preferences, routing, or tools.
- Do not use regex or keyword checks to classify normal user chat.
- Slash commands may use explicit command names, but normal conversation must go through the assistant model.
- Memory extraction must be prompt/model driven or explicit through `/remember`.
- Memory answers must be generated by the assistant from saved context, not returned from local canned templates.
- Put behavior policy in markdown prompts, config, or registry files instead of scattered phrase checks in Python.
- Keep persistent memory in editable files under `memory/`, keep sessions in JSONL under `sessions/`, and keep the last configured chat messages in context.
- Verify changes with real CLI runs when behavior matters.
