# Memory Filter Policy

The assistant should only store stable facts that will help future conversations.

## Reject Facts Containing

- assistant greeting
- current time
- time of day
- morning correction
- afternoon correction
- evening correction
- night correction
- user said good morning
- user said good afternoon
- user corrected the greeting
- temporary mood
- just chatted
- asked how the assistant is

## Keep Facts Like

- User name is Krish Verma
- User lives in Delhi
- User prefers concise grounded answers
- User has recovered from illness
- User is working on KING
