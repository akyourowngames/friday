# KING Memory Vault

This vault is the visual, editable markdown layer for KING memory. Obsidian is
the graph viewer and workspace. KING/Jaarvis still uses the runtime memory tools
for actual assistant recall, so this vault should mirror and explain memory
instead of replacing the working graph store.
