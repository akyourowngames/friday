# Query Memory

Use this when answering from remembered information.

## Steps

1. Read [[index]].
2. Follow the most relevant links into memory pages and source summaries.
3. Use `memory_recall` from [[Memory/Memory Tools]] when runtime recall matters.
4. Synthesize only from read pages and returned tool fields.
5. If the answer is valuable for future work, file it with
   [[Templates/Query Result]] and link it into [[index]].
6. Append [[log]] when a new answer page is filed.

## Answer Style

Ground the answer in the pages and tool results that were actually inspected.
If recall is uncertain, say what was checked and what evidence is missing.
