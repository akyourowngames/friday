# Update Memory

Use this when a stored claim changes, gets stronger evidence, or conflicts with
a newer source.

## Steps

1. Read the existing page and its backlinks.
2. Identify whether the change is an addition, correction, contradiction, or
   retirement.
3. If runtime recall is affected, use [[Memory/Memory Tools]] and require the
   structured result to prove the update path.
4. Preserve old values in a History section instead of erasing context.
5. Update [[index]] and [[log]].
6. Check [[Health/Graph Health]] if the update changes links.

## Contradiction Rule

The old claim should stay traceable. Mark it inactive, link it to
[[Removed/README|Removed Memory]] if needed, and write the new active claim with
its source.
