# Source Summaries

This folder holds LLM-maintained summaries of processed raw sources. Each source
summary should link back to [[Raw/README|Raw Sources]], forward to the affected
memory pages, and include enough evidence for future agents to understand why a
memory changed.

Use [[Templates/Source Summary]] for new summaries.
