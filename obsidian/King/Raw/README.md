# Raw Sources

Put immutable source files here when using the vault as an LLM wiki. Sources can
be articles, notes, transcripts, exports, images, or documents. Do not rewrite
raw sources during wiki maintenance.

After processing a source, create a maintained summary under
[[Sources/README|Source Summaries]], link it to the relevant memory pages, update
[[index]], and append [[log]].
