# Removed Memory

This folder keeps retired claims traceable without keeping them active as memory.

Use this area when:

- The user asks KING to forget a memory.
- A newer source contradicts an older claim.
- A vault-only note is no longer useful but should remain auditable.

Each removal entry should link to [[Workflows/Remove Memory]], cite the runtime
tool result when one exists, and point back to the page that replaced or retired
the claim.
