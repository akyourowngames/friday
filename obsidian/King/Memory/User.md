# User Memory

This page records stable user preferences that affect how KING work should be
done. Runtime recall still belongs to [[Memory/Memory Tools]].

## Preferences

- The user prefers grounded implementation with real verification evidence.
- The user does not want regex, hardcoded behavior, keyword routing, or phrase
  match shortcuts.
- The user expects KING/Jaarvis to use exposed tools when available instead of
  claiming false negatives.
- The user prefers markdown control surfaces for tool behavior unless code
  authority is explicit for the current scope.
