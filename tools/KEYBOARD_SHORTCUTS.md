# Keyboard Shortcuts

Saved shortcuts for `keyboard_shortcut`. Keys use `+` between modifiers and the final key.

## Shortcuts

### copy

- keys: ctrl+c

### paste

- keys: ctrl+v

### save

- keys: ctrl+s

### undo

- keys: ctrl+z

### select_all

- keys: ctrl+a

### new_tab

- keys: ctrl+t

### close_tab

- keys: ctrl+w

### refresh

- keys: f5

### show_desktop

- keys: win+d

### screenshot

- keys: win+shift+s

### task_manager

- keys: ctrl+shift+esc
