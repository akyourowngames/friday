# Terminal Launch Targets

These are launch aliases for Windows app targets that do not always resolve through `start <name>`.

Format:

```text
display name = command candidate | fallback candidate
```

Targets:

terminal = wt.exe | cmd.exe | powershell.exe
windows terminal = wt.exe | cmd.exe | powershell.exe
command prompt = cmd.exe | powershell.exe
cmd = cmd.exe
powershell = powershell.exe
